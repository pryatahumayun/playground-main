# Agentic AI

## What is Agentic AI?

Traditional AI answers questions.

Agentic AI completes tasks.

Instead of simply responding to a prompt, an AI Agent can:

- Plan
- Make decisions
- Use tools
- Retrieve information
- Call APIs
- Execute multiple steps
- Adapt based on previous results

Think of it like giving AI a job instead of asking it a question.

---

## Traditional LLM

```
User

↓

LLM

↓

Answer
```

Example:

> "How many vacation days do I get?"

The AI searches its knowledge and responds.

Done.

---

## Agentic AI

```
User

↓

AI Agent

↓

Plans the work

↓

Uses Tools

↓

Calls APIs

↓

Reads Company Data

↓

Makes Decisions

↓

Returns Completed Task
```

Example:

> "Book me vacation next Friday."

The agent could:

1. Check your vacation balance.
2. Look at your calendar.
3. Verify there are no conflicting meetings.
4. Submit the vacation request.
5. Notify your manager.
6. Send you confirmation.

The AI isn't just answering.

It's doing.

---

# Why is this different?

Traditional AI thinks.

Agentic AI thinks **and acts.**

---

# What gives an AI Agent superpowers?

## 1. LLM

The brain.

Examples:

- GPT
- Claude
- Gemini

The LLM reasons about what should happen.

---

## 2. Memory

The agent remembers previous conversations or previous tasks.

Example:

"I always schedule my dentist on Fridays."

---

## 3. Tools

Agents become useful when they can use tools.

Examples:

- Search
- SQL
- Weather API
- Microsoft Graph
- Azure APIs
- GitHub
- Jira

Without tools...

The AI can only talk.

With tools...

The AI can work.

---

## 4. Planning

Instead of doing one thing...

The AI breaks a request into steps.

Example:

```
Deploy application

↓

Build

↓

Run Tests

↓

Deploy Infrastructure

↓

Deploy Application

↓

Verify Health

↓

Notify Teams
```

---

## 5. Reflection

Some agents check their own work.

Example:

"I couldn't find the file."

↓

Search again.

↓

Different search.

↓

Success.
