# Technology Architecture

Technology architecture focuses on the platforms, standards, and non-functional building blocks used across the enterprise.

## Common topics

- hosting platforms
- cloud standards
- networking patterns
- identity and access approach
- observability standards
- resilience and DR expectations
- approved technology stacks

## Questions it answers

- Which platforms should teams build on?
- Which technologies are strategic, tolerated, or sunset?
- What are the standard patterns for security, networking, and operations?

## Why it matters

Technology architecture helps reduce random tool sprawl and gives teams a stronger default path for building solutions.
