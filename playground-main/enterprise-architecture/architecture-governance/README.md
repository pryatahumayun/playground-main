# Architecture Governance

Architecture governance is how an organization turns architecture from ideas into repeatable decision-making.

## Common governance topics

- review boards and approval paths
- architecture decision records
- standards and exception handling
- reference architecture adoption
- compliance and control checkpoints

## Questions it answers

- Who reviews major design decisions?
- Which standards are mandatory vs recommended?
- How are exceptions documented?
- How do teams prove alignment with architecture expectations?

## Goal

Good governance should create clarity and consistency without turning into slow bureaucracy.
