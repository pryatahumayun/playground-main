# Data Architecture

Data architecture focuses on how data is structured, owned, moved, governed, and consumed across the enterprise.

## Common topics

- domain and conceptual data models
- master data
- system of record decisions
- data lineage
- integration patterns
- reporting vs operational data
- governance and stewardship

## Questions it answers

- Who owns this data?
- Where is the authoritative source?
- How does data move between systems?
- How is quality maintained?
- Which data should be shared, replicated, or transformed?

## Why it matters

Many enterprise problems that look like application issues are actually data ownership or data flow issues.
