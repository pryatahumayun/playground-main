# Cloud Architecture Playground

This is my private learning repository where I document cloud architecture, software engineering, AI, and infrastructure concepts in language that makes sense to me, including what I have implemented in production environments, observed, contributed to in design, or studied through existing system designs to support my own changes.

Repository layout (top-level):

- azure/      - Azure-specific content and labs
- aws/        - AWS-specific content and labs
- ai/         - AI, LLMs, embeddings, RAG and related architecture
- development/ - Development, CI/CD, containers, Kubernetes
- architecture/ - Diagrams, patterns, design records
- projects/   - Sample projects and POCs
- interview/  - Interview questions and mock interviews
- cheatsheets/ - Quick reference sheets
- notes/      - Personal notes and journals
- templates/  - Reusable templates for docs and projects

See each folder's README for more details.
