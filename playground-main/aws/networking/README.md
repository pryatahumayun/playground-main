# Networking

AWS networking starts with the VPC and expands into subnets, routing, security, and connectivity.

## Main topics

- VPC
- subnets
- route tables
- internet gateways
- NAT gateways
- security groups
- load balancers

## Why it matters

- where a workload runs affects reachability and cost
- public vs private subnet choices shape the whole deployment
- most AWS app issues eventually touch networking

## Good to remember

- networking is often the real foundation of AWS architecture
- container and serverless services still rely on the same VPC concepts
