# Terraform

Terraform is a common infrastructure-as-code tool for AWS.

## Common uses

- declare AWS resources in code
- manage repeatable environments
- version infrastructure changes
- build reusable modules

## Main concepts

- provider
- resource
- variable
- module
- output
- state

## Good to remember

- Terraform state is operationally important
- modules help reduce repetition
- plan before apply should be a normal habit
