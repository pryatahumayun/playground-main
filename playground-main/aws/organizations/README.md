# Organizations

AWS Organizations is the multi-account governance layer for AWS environments.

## Common uses

- group accounts under one organization
- separate prod, staging, security, and shared services accounts
- apply governance with SCPs

## Main concepts

- organization
- management account
- member account
- organizational unit
- service control policy

## Good to remember

- multi-account design is a common AWS best practice
- Organizations is about governance and account structure, not day-to-day app deployment
