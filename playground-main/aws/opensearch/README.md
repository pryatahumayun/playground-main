# OpenSearch

Amazon OpenSearch Service is AWS's managed search and analytics offering.

## Common uses

- full-text search
- log search and dashboards
- vector search for RAG systems
- hybrid search across keywords and embeddings

## Main concepts

- domain or collection
- index
- document
- mapping
- query

## Good to remember

- OpenSearch can be used for both observability and application search
- schema and indexing choices matter early
- for RAG, metadata filters and retrieval quality matter as much as the vector store itself
