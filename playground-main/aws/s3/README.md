# S3

Amazon S3 is AWS's object storage service.

## Common uses

- store files, images, backups, and static assets
- host static websites
- keep Terraform state
- act as a source or destination in data pipelines

## Main concepts

- bucket
- object
- storage class
- bucket policy
- lifecycle rules

## Good to remember

- S3 is simple to start with but security settings matter
- bucket names are globally unique
- lifecycle policies help manage cost over time
