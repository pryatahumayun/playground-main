# Synchronous vs Asynchronous

Synchronous communication waits for a direct response. Asynchronous communication lets work continue without waiting for immediate completion.

## What To Know

- synchronous is simpler to reason about for request-response flows
- asynchronous improves resilience and elasticity for longer workflows
- user experience and consistency needs drive the choice

## Good Interview Points

- use synchronous for immediate validation or user feedback
- use asynchronous for heavy background work and integration workflows
- hybrid designs are very common
