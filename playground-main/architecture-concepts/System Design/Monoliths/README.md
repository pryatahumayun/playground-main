# Monoliths

A monolith keeps the application in one deployable unit.

## What To Know

- simpler to build, test, and deploy at small scale
- can become hard to evolve if boundaries are poor
- a modular monolith is often a very strong option

## Good Interview Points

- monolith does not mean bad design
- many systems should start as monoliths
- scaling and team independence pressures may eventually justify decomposition
