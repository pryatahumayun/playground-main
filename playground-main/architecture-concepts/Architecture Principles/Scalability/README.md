# Scalability

Scalability is a system's ability to handle more load without a collapse in performance or operability.

## What To Know

- vertical scaling means adding more power to one node
- horizontal scaling means adding more nodes
- stateless services usually scale more easily than stateful ones
- databases often become the hardest layer to scale

## Good Interview Points

- load balancers help distribute traffic across instances
- caching reduces pressure on downstream systems
- queues help smooth sudden spikes
- scaling application servers is often easier than scaling relational databases
