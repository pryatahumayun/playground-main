# High Cohesion

High cohesion means related responsibilities stay together inside the same module or service.

## What To Know

- each component should have a clear purpose
- mixed responsibilities create confusion and fragile code
- cohesion usually makes systems easier to test and evolve

## Good Interview Points

- a service should own one logical capability well
- high cohesion and loose coupling often work together
- poor cohesion often shows up as bloated services or classes
