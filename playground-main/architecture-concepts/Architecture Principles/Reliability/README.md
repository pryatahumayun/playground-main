# Reliability

Reliability is the ability of a system to behave correctly and consistently over time, even when parts fail.

## What To Know

- availability and reliability are related but not identical
- retries, idempotency, and fallback behavior improve reliability
- reliable systems expect partial failure instead of pretending it will not happen

## Good Interview Points

- a system can be available but still return incorrect results
- durable messaging can preserve work during transient failure
- observability is critical for proving reliability
