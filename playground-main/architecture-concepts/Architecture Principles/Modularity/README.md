# Modularity

Modularity means building a system from well-bounded parts that can be understood and changed independently.

## What To Know

- modules should have clear interfaces
- modularity supports reuse and safer change
- weak boundaries reduce the value of modularity

## Good Interview Points

- modular systems are easier to test and replace piece by piece
- microservices are one form of modularity, but not the only one
- a modular monolith is often a strong middle ground
